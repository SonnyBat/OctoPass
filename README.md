# 🐙 OctoPass

A simple **password and login manager** built in Python using the `tkinter` module.

I made this project to practise using **Tkinter** and working with user input, files, and password generation while doing a challenge where I'm building **one project every day**.

## 🔐 Features

* 🔑 Random password generator
* 💾 Store login details in a text file
* 👤 Save website, email/username, and password credentials
* 🖥️ Simple graphical interface built with Tkinter
* 🐍 Built entirely with Python
* 💬 Commented code, making it easy to experiment with and modify
## 🚀 How to Run

Make sure all the Python files are in the **same folder**.

Then run:

```bash
python main.py
```

That's it! The app should launch and you can start generating passwords and saving your credentials.
